# Решение по находкам (босс)

## Беру
- Находка 1 [high] checkCollision(): чинить ложное столкновение на повороте —
  реальный баг, портит игру.
- Находка 2 [medium] moveSnake(): ускорить отклик поворота (применять направление
  в текущем кадре) — явное улучшение, отклик заметно лучше.

## Заворачиваю
- Находка 4 [low] draw(): цвет еды НЕ трогаем — текущий контраст устраивает,
  это вкусовщина проверяющего.

## Откладываю
- Находка 3 [low] подсказка по управлению: мысль хорошая, но не сейчас — вернёмся,
  когда будет стартовый экран.
