# Задание: установить Handy для голосового ввода

Установи бесплатную локальную утилиту [Handy](https://github.com/cjpais/Handy), чтобы можно было диктовать текст в любую программу офлайн.

Перед установкой проверь, не установлена ли Handy уже в этом окружении. Если установлена — пропусти установку и не устанавливай её поверх. Для распознавания речи Handy нужен Parakeet V3: этот движок устанавливается отдельно.

Если Handy не удастся установить в этом окружении, не останавливай работу: задачи агенту всегда можно набрать текстом.
