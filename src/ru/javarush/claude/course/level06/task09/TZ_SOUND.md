# ТЗ: озвучка Змейки (Web Audio)

Добавить в game/index.html звук на базе Web Audio API (AudioContext), без внешних
аудиофайлов и без интернета — генерировать звук кодом.

1. Событие «поедание еды» (функция eatFood) → короткий звуковой сигнал (бип) при
   каждом поедании.
2. Фон → зацикленный фоновый тон/трек, стартует с началом игры и играет по кругу.

Проверяемо в коде: в index.html появляется AudioContext, вызов воспроизведения
привязан к событию поедания, и есть фоновый источник, который звучит непрерывно,
по кругу, всю игру.
