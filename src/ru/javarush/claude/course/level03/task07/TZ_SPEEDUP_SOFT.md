# ТЗ: мягкое ускорение Тетриса

Добавь в рабочий `tetris/index.html` нарастающую скорость падения фигур —
так, чтобы играть оставалось можно.

## Требование
- Скорость падения плавно растёт со счётом: за каждые набранные 100 очков
  интервал между шагами падения сокращается примерно на 10%.
- Есть жёсткий нижний предел: интервал падения НЕ становится меньше 120 мс на
  клетку, как бы много очков ни набрали. Ниже этого порога не разгоняем —
  иначе игра станет неиграбельной.
- Остальную механику игры (движение, поворот, сбор линий, счёт, конец игры)
  не трогаем.
