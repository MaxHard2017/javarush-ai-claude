
# ТЗ: страница-визитка о себе

Собери одну статическую страницу-визитку в одном файле `card.html`
(HTML + CSS внутри, без внешних зависимостей и без базы данных).

## Что на визитке
- Имя — крупным заголовком-героем.
- Пара строк о себе — короткое описание, кто ты и чем занимаешься.
- Контакты — почта и ссылка (или пара ссылок), по которым тебя найти.

## Вид
- Аккуратный, опрятный вид: читаемый шрифт, воздух между блоками,
  выровненные отступы, единый спокойный стиль.
- Страница цельная — всё выглядит как одна связная карточка, а не список кусков.

## Ограничения
- Одна статическая страница целиком в одном файле `card.html`.
- Без внешних зависимостей, без базы данных, без бэкенда.
