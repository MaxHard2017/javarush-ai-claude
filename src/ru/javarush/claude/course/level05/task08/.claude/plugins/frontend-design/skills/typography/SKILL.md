# Навык: typography

Когда правишь типографику и ритм, держи в голове:

- **Иерархия заголовков.** Заголовок-герой заметно крупнее подзаголовка;
  один шаг размера между уровнями, без каши.
- **Межстрочный интервал.** `line-height` 1.4–1.6 для текста — читаемо, не слипается.
- **Отступы-ритм.** Единый шаг вертикальных отступов между секциями; воздух
  вокруг блоков вместо слипшихся краёв.
- **Выравнивание.** Общая сетка и поля; элементы выстроены по одной линии.

Меняй только оформление (CSS). Текст и структуру разметки не трогай.
