# frontend-design

Плагин под веб-дизайн из официального каталога `claude-plugins-official`.
Пачка скилов, которая причёсывает готовую статическую страницу целиком:
типографику, отступы, иерархию, палитру и согласованность стиля.

Установлен командой:

    /plugin install frontend-design@claude-plugins-official

## Скилы в наборе
- **polish** — общий визуальный лоск: палитра, тени, плавность, типографика.
- **typography** — иерархия заголовков, межстрочный интервал, ритм отступов.

Меняет только слой вида (CSS/разметку). Смысл и структуру страницы не трогает.
