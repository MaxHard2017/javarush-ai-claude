# Навык: polish

Когда нужно улучшить внешний вид, применяй последовательно:

- **Палитра.** Согласованная гамма из 3–4 цветов; тёмный фон под акценты.
- **Тени и свечение.** Мягкие `box-shadow`; для акцентов — свечение через
  `box-shadow`/`filter`.
- **Плавность.** Переходы состояний через `transition`; появление — через
  `@keyframes`, без резких скачков.
- **Типографика.** Один акцентный шрифт для заголовков/счёта, читаемый
  межстрочный интервал.

Меняй только слой вида (CSS/разметку). Логику (JS) не трогай.
