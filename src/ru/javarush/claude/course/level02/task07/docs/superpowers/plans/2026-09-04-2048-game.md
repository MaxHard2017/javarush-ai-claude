# Игра 2048 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать автономную игру 2048 на поле `4×4` в одном `index.html`, строго по `TZ_2048 copy.md`, с корректными слияниями, управлением клавиатурой/свайпами, состояниями победы/поражения и адаптивной вёрсткой.

**Architecture:** Один HTML-файл содержит разметку, CSS и JavaScript. Игровая модель хранится отдельно от DOM как массив из `16` чисел, а ход вычисляется чистыми функциями: обработка линии → сборка нового поля → добавление плитки → проверка победы/поражения → отрисовка. DOM отвечает только за отображение и ввод; флаг `isAnimating` блокирует повторный ввод на `120 мс`, не ставя события в очередь.

**Tech Stack:** Нативный HTML5, CSS Grid, vanilla JavaScript, Web APIs `KeyboardEvent`, `TouchEvent`, `setTimeout`; внешние библиотеки, ресурсы и шрифты не используются.

**Spec:** `TZ_2048 copy.md`

## Global Constraints

- Одна автономная страница: вся разметка, стили и логика находятся в `index.html`.
- Игровое поле строго `4×4`; пустая ячейка хранится как `0`.
- Новые плитки: значение `2` с вероятностью `90%`, `4` — `10%`; позиция равновероятна среди списка пустых ячеек.
- После успешного хода добавляется ровно одна плитка, после неуспешного — ни одной.
- Исходная плитка участвует не более чем в одном слиянии за ход; обработка линии идёт от края движения.
- Проверка победы выполняется раньше проверки поражения; после победы/поражения ходы игнорируются.
- Клавиатура: стрелки и `WASD`; свайп по полю от `30 CSS-пикселей`, равная диагональ игнорируется, одно касание даёт не более одного хода.
- Ввод блокируется на `120 мс` анимации и не ставится в очередь.
- Размер поля: `min(448px, calc(100vw - 32px))`; промежуток ячеек `8px`; кнопки минимум `44px`.
- Цвета плиток и текстовые размеры берутся без изменений из раздела 9 ТЗ.
- В консоль разрешены только записи о старте партии, важном событии и завершении партии; лог в каждом кадре запрещён.
- `.claude` и `.javarush` не изменяются.

- [ ] **Step 1: Создать минимальную HTML-оболочку и базовые константы**

Добавить `<!doctype html>`, контейнер игры и скрипт с такими базовыми значениями:

```js
const SIZE = 4;
const CELL_COUNT = SIZE * SIZE;
const ANIMATION_MS = 120;
const DIRECTIONS = new Set(['up', 'down', 'left', 'right']);

function createEmptyBoard() {
  return Array(CELL_COUNT).fill(0);
}
```

Не смешивать вычисление поля с чтением DOM: функции модели не должны обращаться к элементам страницы.

- [ ] **Step 2: Реализовать выбор пустой ячейки и генерацию значения**

Сначала собрать индексы пустых ячеек, затем выбрать индекс из этого списка. Не делать бесконечные случайные попытки занятой позиции:

```js
function getEmptyIndices(board) {
  return board.reduce((indices, value, index) => {
    if (value === 0) indices.push(index);
    return indices;
  }, []);
}

function spawnTile(board) {
  const emptyIndices = getEmptyIndices(board);
  if (emptyIndices.length === 0) return false;

  const cellIndex = emptyIndices[Math.floor(Math.random() * emptyIndices.length)];
  board[cellIndex] = Math.random() < 0.9 ? 2 : 4;
  return true;
}
```

- [ ] **Step 3: Реализовать обработку одной линии без повторного слияния**

Сжать ненулевые значения, пройти слева направо (в вызывающем коде линия уже ориентирована к краю движения), объединять только соседнюю равную пару и после слияния пропускать результат. Это даёт обязательные результаты:

```js
function processLine(line) {
  const compact = line.filter(value => value !== 0);
  const result = [];
  let score = 0;

  for (let index = 0; index < compact.length; index += 1) {
    if (compact[index] === compact[index + 1]) {
      const merged = compact[index] * 2;
      result.push(merged);
      score += merged;
      index += 1;
    } else {
      result.push(compact[index]);
    }
  }

  while (result.length < SIZE) result.push(0);
  return {
    line: result,
    score,
    changed: result.some((value, index) => value !== line[index])
  };
}
```

Проверить до перехода дальше: `[2,2,2,0] → [4,2,0,0]`, `[2,2,4,4] → [4,8,0,0]` с приростом `12`, `[2,2,2,2] → [4,4,0,0]` с приростом `8`, `[4,4,8,0] → [8,8,0,0]`.

- [ ] **Step 4: Реализовать сборку строк/столбцов в четырёх направлениях**

Для каждой строки/колонки извлекать линию в направлении движения, передавать её в `processLine`, а результат записывать в новое поле в том же ориентированном порядке. Для `right` и `down` разворачивать линию до обработки и после обработки. Исходный `board` не мутировать:

```js
function moveBoard(board, direction) {
  if (!DIRECTIONS.has(direction)) {
    return { board: board.slice(), scoreGain: 0, changed: false };
  }

  const next = createEmptyBoard();
  let scoreGain = 0;

  for (let lineIndex = 0; lineIndex < SIZE; lineIndex += 1) {
    const indices = getLineIndices(lineIndex, direction);
    const source = indices.map(index => board[index]);
    const processed = processLine(source);
    processed.line.forEach((value, position) => {
      next[indices[position]] = value;
    });
    scoreGain += processed.score;
  }

  return {
    board: next,
    scoreGain,
    changed: next.some((value, index) => value !== board[index])
  };
}
```

`getLineIndices(lineIndex, direction)` должен возвращать индексы от ближайшего к краю движения к дальнему; для движения вправо/вниз порядок индексов соответственно обратный. Отдельно проверить, что плитки не переходят через край.

- [ ] **Step 5: Реализовать проверки победы и поражения**

`hasWon` возвращает `true`, если есть `2048`. `hasLost` сначала требует отсутствие нулей, затем проверяет только горизонтальных и вертикальных соседей:

```js
function hasWon(board) {
  return board.includes(2048);
}

function hasLost(board) {
  if (board.some(value => value === 0)) return false;
  for (let row = 0; row < SIZE; row += 1) {
    for (let column = 0; column < SIZE; column += 1) {
      const index = row * SIZE + column;
      if (column + 1 < SIZE && board[index] === board[index + 1]) return false;
      if (row + 1 < SIZE && board[index] === board[index + SIZE]) return false;
    }
  }
  return true;
}
```

Проверить полное поле с равной горизонтальной/вертикальной парой и полное поле без таких пар; диагональные равенства не должны отменять поражение.

- [ ] **Step 6: Запустить статическую проверку скрипта и зафиксировать результат**

Извлечь содержимое `<script>` во временный файл вне служебных папок и запустить `node --check` (или эквивалентную синтаксическую проверку доступным JS-движком). Ожидаемый результат — отсутствие синтаксических ошибок. В репозиторий временный файл не добавлять.

- [ ] **Step 1: Добавить состояние и единственный сценарий запуска партии**

Использовать объект состояния:

```js
const state = {
  board: createEmptyBoard(),
  score: 0,
  status: 'playing',
  isAnimating: false
};

function startNewGame() {
  state.board = createEmptyBoard();
  state.score = 0;
  state.status = 'playing';
  state.isAnimating = false;
  spawnTile(state.board);
  spawnTile(state.board);
  render();
  console.log('[2048] Партия началась');
}
```

Две стартовые плитки создаются после очистки поля; при корректной реализации они всегда находятся в разных ячейках.

- [ ] **Step 2: Реализовать успешный и неуспешный ход**

`handleMove` должен выйти без изменений, если направление неизвестно, `state.status !== 'playing'` или `state.isAnimating === true`. Для успешного хода заменить модель результатом `moveBoard`, прибавить только `scoreGain`, добавить одну плитку если есть свободное место, затем проверить победу и только потом поражение. Неуспешный ход не менять и не запускать таймер:

```js
function handleMove(direction) {
  if (!DIRECTIONS.has(direction) || state.status !== 'playing' || state.isAnimating) return;

  const result = moveBoard(state.board, direction);
  if (!result.changed) return;

  state.board = result.board;
  state.score += result.scoreGain;
  spawnTile(state.board);
  render();

  state.isAnimating = true;
  window.setTimeout(() => {
    state.isAnimating = false;
    if (hasWon(state.board)) {
      state.status = 'won';
      console.log('[2048] Партия завершена: победа');
    } else if (hasLost(state.board)) {
      state.status = 'lost';
      console.log('[2048] Партия завершена: поражение');
    }
    render();
  }, ANIMATION_MS);
}
```

Лог важного события разрешается добавить только при появлении новой максимальной плитки, например при переходе к `2048`; не печатать ничего из `render` или игрового цикла.

- [ ] **Step 3: Подключить клавиатуру с фильтрацией клавиш и отменой прокрутки**

Использовать один обработчик `keydown`; буквы сравнивать через `event.key.toLowerCase()`. Для стрелок вызывать `preventDefault()`, чтобы активная игра не прокручивала страницу; остальные клавиши игнорировать:

```js
const keyToDirection = {
  ArrowUp: 'up', ArrowDown: 'down', ArrowLeft: 'left', ArrowRight: 'right',
  w: 'up', s: 'down', a: 'left', d: 'right'
};

document.addEventListener('keydown', event => {
  const key = event.key.length === 1 ? event.key.toLowerCase() : event.key;
  const direction = keyToDirection[key];
  if (!direction) return;
  if (event.key.startsWith('Arrow')) event.preventDefault();
  handleMove(direction);
});
```

- [ ] **Step 4: Подключить сенсорный ввод с порогом и защитой от мультитача**

Слушать `touchstart`/`touchend` только на игровом поле. Хранить одну начальную точку и флаг `touchTracking`; игнорировать событие, если `touches.length !== 1`, сбрасывать tracking после `touchend`, вычислять `dx`/`dy`, требовать `Math.max(absDx, absDy) >= 30` и строгое превосходство одной оси:

```js
let touchStart = null;
let touchTracking = false;

boardElement.addEventListener('touchstart', event => {
  if (event.touches.length !== 1) {
    touchStart = null;
    touchTracking = false;
    return;
  }
  const touch = event.touches[0];
  touchStart = { x: touch.clientX, y: touch.clientY };
  touchTracking = true;
}, { passive: true });

boardElement.addEventListener('touchend', event => {
  if (!touchTracking || !touchStart) return;
  const touch = event.changedTouches[0];
  const dx = touch.clientX - touchStart.x;
  const dy = touch.clientY - touchStart.y;
  touchStart = null;
  touchTracking = false;

  const absDx = Math.abs(dx);
  const absDy = Math.abs(dy);
  if (Math.max(absDx, absDy) < 30 || absDx === absDy) return;
  handleMove(absDx > absDy
    ? (dx > 0 ? 'right' : 'left')
    : (dy > 0 ? 'down' : 'up'));
});
```

Учесть `touchcancel` и сбрасывать tracking; одно `touchend` может вызвать максимум один `handleMove`.

- [ ] **Step 5: Подключить кнопку `Новая игра` и проверить блокировки состояний**

Кнопка вызывает `startNewGame()` независимо от `playing`, `won`, `lost` и `isAnimating`; она не должна проходить через `handleMove`. Проверить повторный клик: старый счёт и поле полностью заменяются, появляется ровно две плитки.
