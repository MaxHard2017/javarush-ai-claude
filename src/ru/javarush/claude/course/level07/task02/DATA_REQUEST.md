# DATA_REQUEST — заказ данных для радара землетрясений

Источник: публичный сервис землетрясений (USGS, GeoJSON-feed).

| Поле        | Что это          | Зачем на экране                 |
|-------------|------------------|---------------------------------|
| magnitude   | сила толчка      | размер точки на карте           |
| place       | место (текст)    | подпись/тултип точки            |
| coordinates | широта, долгота  | позиция точки на карте          |
| time        | свежесть толчка  | яркость точки (свежий — ярче)   |

Граница: берём только поля, которые реально ложатся на картинку.
