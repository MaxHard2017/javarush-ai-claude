# DATA_SCHEMA — раскладка полей на экране радара

Каждое поле данных отвечает за отдельное визуальное свойство точки землетрясения на карте.

- `magnitude` → размер точки: чем выше магнитуда, тем больше точка.
- `place` → подпись точки: название места показывается рядом с точкой.
- `coordinates` → позиция на карте: координаты определяют, где расположить точку.
- `time` → яркость точки: чем свежее землетрясение, тем ярче точка.

Схема использует только поля, перечисленные в `DATA_REQUEST.md`.
