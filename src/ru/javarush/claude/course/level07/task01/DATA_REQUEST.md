# Бланк запроса данных для радара землетрясений

## Источник

- **Сервис:** USGS Earthquake Hazards Program — публичная GeoJSON-лента землетрясений за последние 24 часа.
- **Адрес:** <https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson>
- **Запрос:** `GET`, формат ответа — GeoJSON `FeatureCollection`; ключ API не требуется.

## Запрашиваемые поля

| Что отображает радар | Поле в GeoJSON | Как используется |
|---|---|---|
| Сила толчка | `properties.mag` | Значение магнитуды определяет размер точки. |
| Место толчка на карте | `geometry.coordinates[0]`, `geometry.coordinates[1]` | Координаты точки: `[долгота, широта]`. В GeoJSON третий элемент — глубина; он приходит в ответе, но для радара не используется. |
| Давность толчка | `properties.time` | Время события в миллисекундах Unix; давность вычисляется как `текущее время − properties.time`. |
| Название места | `properties.place` | Текстовая подпись рядом с точкой на карте. Используется готовое название из сервиса, без отдельного геокодирования. |

## Граница запроса

USGS-лента возвращает объект события целиком. Для радара извлекать и использовать только магнитуду, координаты, время события и название места — эти значения непосредственно отображаются на картинке. Остальные свойства ответа, включая глубину, идентификатор, статус проверки и ссылки, игнорировать.

Если у события нет координат, магнитуды или времени, его нельзя корректно отобразить как точку радара; такое событие пропустить. Если отсутствует только `properties.place`, показать точку без подписи.
