Шпаргалка по терминалу

Четыре команды, с которых начинается работа в чёрном окне.
У терминала всегда есть текущая папка — эти команды про неё.
pwdот print working directory
Показывает, в какой папке ты сейчас находишься. Первая команда, когда непонятно, где ты вообще.
$ pwd /Users/tema/projects
lsот list
Печатает список файлов и папок «здесь» — в текущей папке. Оглядеться вокруг.
$ ls arkanoid.html clicker.html cheatsheet.html
cdот change directory
Переход в другую папку. cd games — зайти внутрь, cd .. — подняться на уровень выше.
$ cd games $ pwd /Users/tema/projects/games
mkdirот make directory
Создаёт новую папку. Нужной папки ещё нет — сделай её этой командой и сразу зайди через cd.
$ mkdir my-project $ cd my-project
Значок # в командах — это комментарий, пояснение для человека.
Компьютер его не выполняет.
